# Data and preprocessing boundary

## Bundled synthetic data

`processed/example_realistic.npy` is the deterministic 200 x 60 synthetic matrix used for the feedback-ablation mechanism check. It is generated by `src/data/synthetic_realistic.py` with seed 0.

## Audited GEO preprocessing supplied in this package

The submission version intentionally implements only the two preprocessing paths for which the current study has an explicit, auditable public-source description. Use `src/data/preprocess_real.py`.

### Tissp — GDS596 / GPL96

Input: the GDS596 SOFT table. The script retains rows with a non-empty `IDENTIFIER` and complete numeric GSM sample values, aggregates probes mapping to the same gene identifier by sample-wise mean, then applies a whole-matrix z-score using the population standard deviation (`ddof=0`). Audited final shape: **14,063 x 158**.

```bash
python src/data/preprocess_real.py tissp \
  --gds-soft PATH/GDS596.soft.gz \
  --out data/processed/tissp.npy
```

### Cocel-alt sensitivity dataset — GSE35896 / GPL570

This is an Affymetrix GPL570 microarray sensitivity dataset, **not** an exact reproduction of the CCLE/RNA-seq dataset described as Cocel in OAEVOB. Input: the GSE35896 RMA series matrix plus a GPL570 annotation table. The script retains complete expression rows with an unambiguous single `Gene Symbol`, aggregates duplicate probes by sample-wise mean, and applies the same whole-matrix z-score (`ddof=0`). Audited final shape: **20,848 x 62**.

```bash
python src/data/preprocess_real.py cocel-alt \
  --series-matrix PATH/GSE35896_series_matrix.txt.gz \
  --platform-annotation PATH/GPL570_annotation.txt_or_gz \
  --out data/processed/cocel_alt.npy
```

The generated `.metadata.json` records the resulting shape and SHA-256 checksum. A newly downloaded source may have annotation-version differences; verify the final shape and checksum before describing it as an exact rerun of the study matrix.
