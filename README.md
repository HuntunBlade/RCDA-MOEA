# RCDA-MOEA — submission reproducibility package

Code and audit artifacts for the manuscript on **row/column structural-diversity feedback in multi-objective evolutionary biclustering**.

The package is curated for peer review: it contains the RCDA-MOEA implementation, the validated NSGA-II comparison baseline, experiment runners, audited synthetic experiments, selected saved real-data outputs, and explicit preprocessing code for the two GEO datasets whose source-to-matrix construction is documented here. Unverified literature adapters and development backups are excluded.

## 1. Environment

Recommended: Python 3.10+.

```bash
python -m venv .venv
# Windows PowerShell
.venv\Scripts\Activate.ps1
# Windows Git Bash
source .venv/Scripts/activate
pip install -r requirements.txt
python run_tests.py
```

`requirements-lock.txt` records the exact package versions used for the final validation of this archive (Python 3.13.5). `requirements.txt` retains portable lower bounds.

Expected test output contains four `PASS` lines. The tests explicitly verify that RCDA-MOEA and NSGA-II report final HV from the same post-selection search budget.

## 2. Important metric convention

For both algorithms, **final performance HV is computed from the returned final Pareto archive after the last environmental-selection step**. `hv_log[-1]` follows the same convention.

RCDA's stagnation controller still observes a pre-offspring HV signal, because that signal is needed to choose the crossover probability for the next reproduction step. The implementation therefore keeps the controller signal separate from the post-selection performance trajectory:

- diagnostic `hv` / `hv_feedback`: pre-offspring HV used by the controller;
- diagnostic `hv_post`: post-selection HV after that generation;
- returned `hv_log`: post-selection performance trajectory.

This separation removes an earlier off-by-one logging ambiguity without changing the RCDA feedback mechanism.

## 4. Synthetic feedback ablation — directly reproducible

The bundled `data/processed/example_realistic.npy` is deterministically generated by `src/data/synthetic_realistic.py` with seed 0 and shape 200 x 60.

The default command reads the documented settings from `configs/synthetic_ablation.yaml` and runs exactly the four manuscript variants:

```bash
python run_ablation.py
```

Equivalent explicit command:

```bash
python run_ablation.py \
  --data data/processed/example_realistic.npy \
  --out results/reproduced_ablation \
  --runs 30 --population 60 --generations 100
```

The full variant uses `epsilon=1e-3`, `allocation_sharpness=3`, `hv_epsilon=0.02`, `pc_base=0.7`, and `pc_max=0.95`. The four variants are `full`, `no_structural_diversity`, `no_hv_feedback`, and `no_feedback`; no duplicate fifth ablation is generated.

Analyze the saved fronts with:

```bash
python run_analysis.py \
  --data data/processed/example_realistic.npy \
  --results-root results/reproduced_ablation \
  --algos full no_structural_diversity no_hv_feedback no_feedback
```

## 5. Controlled row/column-ratio experiments

Main design: fixed `m=100`, ratios `{2,5,10,20,50,100,200,500,1000}`, 20 independently generated matrices per ratio, population 60, 100 generations, and paired RCDA/NSGA-II algorithm seeds.

```bash
python run_controlled_ratio.py --out results/reproduced_controlled_ratio
```

Quick development check:

```bash
python run_controlled_ratio.py --smoke --out results/tmp/controlled_ratio_smoke
```

Fixed-encoding-length sensitivity:

```bash
python run_controlled_fixed_length.py --out results/reproduced_fixed_length
python analyze_controlled_fixed_length.py --root results/reproduced_fixed_length
```

Both runners compute primary `DeltaHV = HV_RCDA - HV_NSGAII` directly from the final archives.

## 6. Real datasets

Raw biological datasets are not redistributed. `data/README.md` documents the reproducibility boundary.

Audited preprocessing code is supplied for:

- **Tissp:** GDS596/GPL96 -> non-empty `IDENTIFIER` -> complete numeric values -> duplicate probes averaged by gene -> whole-matrix z-score (`ddof=0`), audited shape 14,063 x 158.
- **Cocel-alt:** GSE35896/GPL570 RMA microarray -> unambiguous single Gene Symbol -> duplicate probes averaged -> whole-matrix z-score (`ddof=0`), audited shape 20,848 x 62. This is a sensitivity dataset, not an exact reproduction of the OAEVOB Cocel/CCLE dataset.

Mouse and Ustilago are represented by saved result artifacts for audit; this public archive does not claim an exact source-to-matrix reconstruction for them.

Example real-data runs after preparing a verified matrix:

```bash
python run_rcda.py --data PATH.npy --out results/my_rcda \
  --runs 30 --population 60 --generations 100 \
  --min-rows DATASET_SPECIFIC --min-cols DATASET_SPECIFIC \
  --init-density DATASET_SPECIFIC

python run_baselines.py --data PATH.npy --algo nsga2 --out results/my_nsga2 \
  --runs 30 --population 60 --generations 100 --pc 0.8 \
  --min-rows DATASET_SPECIFIC --min-cols DATASET_SPECIFIC \
  --init-density DATASET_SPECIFIC
```

The real-data NSGA-II performance baseline uses fixed `Pc=0.8`. The controlled mechanism experiments explicitly use `Pc=0.7` to match RCDA's base crossover probability.

## 7. Saved results and audit

Run:

```bash
python audit_saved_results.py
```

The script verifies per-seed archive availability, rebuilds complete summaries where possible, recomputes final HV from final archives with the study reference points, and writes machine-readable audit outputs under `results/submission_audit/`.

The package deliberately distinguishes:

1. **Directly reproducible from bundled data:** synthetic ablation and synthetic controlled experiments.
2. **Saved outputs available for audit:** real-data RCDA/NSGA-II final archives and statistical artifacts.
3. **Requires external source data:** fresh real-dataset reruns.

## 8. Statistical protocol

Paired comparisons use the same seed on RCDA-MOEA and NSGA-II. The analysis utilities provide two-sided Wilcoxon signed-rank tests, paired mean differences, Cohen's `d_z`, matched-pairs rank-biserial correlation, and a 20,000-resample paired bootstrap with RNG seed `20260910`. The primary four-real-dataset HV family uses Holm correction.

HV is evaluated in the original two-objective space `(MSR, f2)`, with `f2 = 1 - |R||C|/(n*m)`. Dataset-specific shared reference points are used. Points outside the reference box are ignored, never clipped.
